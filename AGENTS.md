# AGENTS.md

## Project Overview

Nuxt 4 minimal starter with TanStack AI chat (Vue 3 + TypeScript). Single-page app with an SSE chat endpoint.

## Commands

- `pnpm dev` — dev server on `localhost:3000`
- `pnpm build` — production build (`nuxt build`)
- `pnpm preview` — preview production build
- `pnpm lint` — `oxlint`
- `pnpm fmt` — `oxfmt` (format in place)
- `pnpm fmt:check` — `oxfmt --check` (verify formatting without writing)
- `pnpm install` — also runs `postinstall: nuxt prepare`

## Toolchain

- **Package manager**: pnpm (workspace config in `pnpm-workspace.yaml`)
- **Linter/formatter**: oxlint + oxfmt (not ESLint/Prettier). `.oxfmtrc.json` enforces `singleQuote: true`.
- **TypeScript**: `tsconfig.json` references `.nuxt/tsconfig.*.json` generated by Nuxt — do not edit those directly.

## Architecture

- `app/` — Vue app entrypoint (`app.vue`) + components. Uses `<script setup lang="ts">`.
- `server/api/` — Nitro server routes (`defineEventHandler`, `readBody`, `setResponseHeaders`, `createError`).
- `public/` — static assets.
- `.nuxt/`, `.output/`, `.data/`, `.nitro/` — build artifacts, gitignored.

## Key Details

- Chat endpoint at `POST /api/chat` uses `@tanstack/ai` with `openaiCompatibleText` adapter pointing to `http://localhost:8080/v1` (local AI server).
- No test framework configured. No CI workflows.
- `pnpm install` triggers `nuxt prepare` via `postinstall` script — required after adding new modules or dependencies.
